Installation guide ↗

Your list stays yours.

Favorites are saved in this browser only, separately from the terminal app. Catalog requests and poster images contact external providers. If a direct API request is blocked, it is retried through corsproxy.io, which receives that request URL, including any search terms. No analytics are included.
